# Agenda GlowUp — Protótipo Sutil

Protótipo de agenda online para serviços de beleza, criado para praticar estrutura de páginas, estilização visual e interações básicas com HTML, CSS e JavaScript.

## Visão geral

A interface utiliza uma apresentação leve e organizada para orientar o visitante entre a página inicial e o fluxo de agendamento. O projeto faz parte de uma série de estudos de interfaces para serviços de beleza.

## Tecnologias

| Tecnologia | Uso |
| --- | --- |
| HTML5 | Estrutura das páginas |
| CSS3 | Layout, tipografia e responsividade |
| JavaScript | Interações da interface |

## Estrutura

```text
css/         # Folhas de estilo
js/          # Scripts de interação
index.html   # Página principal
```

## Como visualizar

Como o projeto é estático, basta clonar o repositório e abrir `index.html` no navegador:

```bash
git clone https://github.com/Raydev15/agenda-glowup-prototipo-sutil.git
cd agenda-glowup-prototipo-sutil
```

Também é possível iniciar um servidor local simples:

```bash
python3 -m http.server 8000
```

Depois, acesse `http://localhost:8000`.
